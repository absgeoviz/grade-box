Help & User Guide

🗺️ Map View Workflow

  1. Login to the application
  2. Map view will be displayed by default
  3. Click "Sidebar" button to show sidebar (if hidden)
  4. Fill filter form (defaults: SIS, OB, Today)
  5. Click "Submit" button to fetch data
  6. Data table appears in sidebar below filter
  7. Points are displayed on the map
  8. Click marker on map to view details popup
  9. Click row in data table to zoom to location

📊 Dashboard Workflow

  1. Click "Dashboard" menu to switch to dashboard view
  2. Click "Sidebar" button to show sidebar (if hidden)
  3. Fill filter form (defaults: SIS, OB, Today)
  4. Click "Submit" button
  5. Charts are displayed in main view
  6. Data table shows below charts with all filtered data
  7. Click on chart bars to filter data table
  8. Data table will show only selected category records
  9. Table title updates to show current filter

🔍 Filter Default Values

  • Date: Today's date (auto-populated)
  • Mitra Kerja: SIS (default selection)
  • Material: OB (default selection)
  • Reset Button: Restores all defaults

💡 Features & Tips

  • • Sidebar Toggle: Show/hide sidebar for better view
  • • Export CSV: Download current table data
  • • Interactive Charts: Click bars to filter table
  • • Map Markers: Color-coded by Front Type
  • • Dashboard Table: Shows in main view below charts
  • • Map Table: Shows in sidebar for quick reference
